### How to publish this on GitHub Pages

1. Create a new **public** repository named exactly **`rashid-shahbaz.github.io`**. It must match your GitHub username.
2. Upload `index.html`, `Rashid_Shahbaz_Sharif_CV.pdf` and `README.md`. Click **Add file → Upload files**, then **Commit changes**.
3. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, then pick **main** and **/(root)**, and click **Save**.
4. After 1–2 minutes your site is live at **https://rashid-shahbaz.github.io**.

To add or edit projects later, open `index.html` and edit the `projects` list near the bottom of the file.
